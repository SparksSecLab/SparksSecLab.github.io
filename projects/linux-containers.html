01 // PROJECT OVERVIEW

Linux Infrastructure for the Home Lab

This project focuses on building practical Linux server administration and container management skills through services deployed inside my home lab.

Ubuntu Server runs as a virtual machine in VMware Workstation Pro and provides the Linux environment used to deploy and manage Docker-based services.

Rather than installing services only to demonstrate that they run, the environment is used to support other lab projects and create opportunities to troubleshoot real configuration, networking, and service issues.

06 // TROUBLESHOOTING WORKFLOW

From Container to Application

When a service does not work as expected, troubleshooting begins by determining whether the issue exists at the Linux host, Docker, container, network, dependency, or application layer.

This provides practice diagnosing systems where multiple services depend on each other rather than treating an application as a single isolated component.
