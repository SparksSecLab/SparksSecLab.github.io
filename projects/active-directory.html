01 // PROJECT OVERVIEW

Building a Windows Domain Environment

This lab was created to gain hands-on experience administering a Windows domain environment and troubleshooting common issues that can occur in business IT environments.

The environment includes a Windows Server domain controller and domain-joined Windows client systems running inside VMware Workstation Pro.

The lab is used alongside my Help Desk Lab to create realistic troubleshooting scenarios involving user accounts, authentication, permissions, Group Policy, and access to network resources.
