01 // INCIDENT
TICKET INC0002

Workstation Running Extremely Slow

RESOLVED

A simulated Operations department user reported that applications were taking significantly longer than normal to open and occasionally freezing. The workstation had been operating normally the previous day, and restarting the computer had not resolved the issue.

DEPARTMENT

Operations

WORKSTATION

WS-002

MEMORY

8 GB RAM

02 // INITIAL ASSESSMENT

Determine the Source of the Performance Problem

The initial report established that the issue appeared to affect a single workstation. Several possible causes were considered before making changes to the system.

01

MEMORY PRESSURE

Excessive RAM utilization caused by applications, browser tabs, or extensions.

02

CPU / DISK

High processor or disk utilization affecting workstation performance.

03

BACKGROUND SERVICES

Windows Update, security software, or another background process consuming resources.

04

RECENT CHANGE

Newly installed software, browser extensions, or configuration changes.

03 // INVESTIGATION
01

Review System Resources

Windows Task Manager was used to investigate resource utilization and determine whether CPU, memory, or disk activity could explain the reported performance issue.

02

Investigate Browser Processes

Chrome Task Manager was used to examine memory usage by individual browser tabs and extensions. An unofficial Spotify Radio extension was using approximately 1.84 GB of memory.

Additional open tabs and extensions were also consuming memory on a workstation with only 8 GB of RAM.

03

Identify Recent Changes

The user reported installing the unofficial Spotify Radio extension the previous day, providing a relevant recent change to investigate.

The timing supported the extension as a likely contributor, but the extension was not treated as the confirmed cause until remediation was tested.

05 // REMEDIATION
CONTROLLED CHANGE

Disable → Test → Verify

SUCCESS

The unofficial Spotify Radio extension was disabled and unnecessary browser tabs were closed. The user was then asked to continue using the workstation and repeat the tasks that had previously been slow.

Security software was not disabled during troubleshooting simply because it consumed system resources.

06 // VERIFICATION

User Confirmed Performance Improvement

After the controlled changes were made, the simulated user reported that the workstation was running much better.

The improvement following removal of the high-memory browser workload supported the conclusion that excessive browser and extension memory consumption was responsible for the performance issue.

07 // ROOT CAUSE

Excessive Browser Memory Usage

The primary contributor was an unofficial Spotify Radio Chrome extension consuming approximately 1.84 GB of memory on a workstation with 8 GB of RAM.

Multiple browser tabs and additional extensions added further memory pressure, resulting in degraded workstation performance.

08 // TROUBLESHOOTING METHOD

Evidence Before Remediation

Customer Report → Determine Scope → Review Resource Utilization → Investigate Recent Changes → Form Hypothesis → Make Controlled Change → Verify Performance → Document Resolution

09 // LESSONS LEARNED

CHECK THE EVIDENCE

Resource utilization provides measurable evidence instead of relying only on the description that a computer feels slow.

ASK ABOUT CHANGES

Recent software or configuration changes can help narrow the investigation.

CONTROL THE TEST

Changing one likely contributor and retesting makes the result more meaningful.

VERIFY WITH THE USER

Resource numbers matter, but resolution should also confirm that the user's original problem is fixed.
