HELP DESK
INFRASTRUCTURE

Deploying a self-hosted Help Desk environment using Ubuntu Server, Docker, osTicket, and Mailpit inside my VMware home lab.

UBUNTU SERVER DOCKER DOCKER COMPOSE OSTICKET MAILPIT
01 // OVERVIEW

Self-Hosted Help Desk Environment

I deployed a dedicated Ubuntu Server virtual machine in VMware Workstation Pro to host the services used for my Help Desk training lab.

Docker and Docker Compose provide the container platform for the environment, allowing services such as osTicket and Mailpit to run as part of a reproducible lab infrastructure.

02 // ARCHITECTURE
SERVICE STACK

Containerized Help Desk Platform

OPERATIONAL

The Help Desk services run inside containers on an Ubuntu Server virtual machine connected to the VMware lab network.

VMware Workstation Pro → Ubuntu Server → Docker / Docker Compose → osTicket + Mailpit

03 // UBUNTU SERVER

Linux Server Foundation

Ubuntu Server provides the Linux operating system foundation for the Help Desk infrastructure. The server runs as a virtual machine and provides the environment used to deploy and manage containerized applications.

Working with the server provides hands-on practice with Linux administration, command-line navigation, package management, service troubleshooting, and network connectivity.

04 // CONTAINER PLATFORM
01

Docker

Docker provides the container runtime used to deploy and operate the Help Desk services on the Ubuntu Server VM.

02

Docker Compose

Docker Compose is used to define and manage the multi-container application stack and its supporting services.

03

Container Troubleshooting

Container status and logs are used to diagnose startup, configuration, dependency, and connectivity problems within the environment.

05 // OSTICKET
TICKETING PLATFORM

osTicket

DEPLOYED

osTicket serves as the ticketing system for my simulated Help Desk environment. It allows incidents to be documented and worked through using a structured support workflow.

INCIDENT TRACKING

Create and manage simulated support tickets.

DOCUMENTATION

Record troubleshooting actions and findings.

RESOLUTION

Document verification and ticket closure.

06 // MAILPIT
EMAIL TESTING

Mailpit

DEPLOYED

Mailpit provides a local email-testing environment for the lab. It allows application-generated messages to be captured and inspected without sending test email through a production mail service.

osTicket → Mailpit → Local Message Inspection

07 // LAB INTEGRATION

Supporting the Help Desk Lab

The containerized infrastructure provides the ticketing and email-testing services used alongside the Windows and Active Directory lab.

Together, the systems provide an environment where I can practice receiving an incident, gathering information, troubleshooting Windows and domain problems, documenting actions, verifying the solution, and closing the incident.
