01 // OVERVIEW

Virtualized Lab Network

VMware Workstation Pro provides the virtualization platform for my home IT lab. The virtual network allows Windows and Linux systems to communicate while providing internet connectivity through NAT.

This network serves as the foundation for the Active Directory environment, Windows client systems, Ubuntu Server services, and Help Desk troubleshooting scenarios.

04 // CONFIGURATION
01

Configure Virtual Adapters

Virtual machine network adapters were configured through VMware Workstation Pro to place the lab systems on the appropriate virtual network.

02

Verify IP Configuration

Windows and Linux networking tools were used to confirm addressing and interface configuration on the virtual machines.

03

Test Connectivity

Connectivity testing was performed between lab systems and external resources to verify that the virtual network was functioning correctly.

05 // VALIDATION

Network Verification

Network configuration was validated using tools such as ipconfig and ping to confirm addressing, communication between virtual machines, and external connectivity.

Verifying the network layer first provides a stable foundation before troubleshooting higher-level services such as DNS, Active Directory, or Help Desk applications.

06 // LAB PURPOSE

Foundation for the IT Lab

The virtual network connects the systems used throughout my portfolio and allows me to practice troubleshooting across multiple operating systems and services in an isolated lab environment.
